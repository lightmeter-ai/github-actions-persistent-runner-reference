# Security policy

## Unsupported snapshot

This repository contains an archived controller with no supported versions and
no commitment to investigate or fix vulnerabilities in the code.

The project intentionally contains no production backend, credentials, runner
registration, service-control commands, Docker cleanup, cloud configuration,
or current Lightmeter integration. Treat any production adaptation as new
security-sensitive infrastructure requiring its own review.

## Accidental disclosure

If this public snapshot accidentally contains a credential, personal data, or
information that creates a risk for a currently operated Lightmeter system, do
not open a public issue. Report the exact file and concern privately to
`hello@lightmeter.io`.

That contact is for accidental disclosure affecting Lightmeter. It is not a
support channel or a promise of vulnerability response for forks or adaptations
of this archived code.
